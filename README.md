# PerthBitDevs
This is the Github repo for the Perth Western Australia BitDevs/Bitcoin Meetup.

Issues are for organising topics for discussion at the monthly meetup and are open to all for submission.

Markdown documents and other content is to serve as a reference or to assist with educating attendees on various concepts or ideas in the Bitcoin ecosystem.
